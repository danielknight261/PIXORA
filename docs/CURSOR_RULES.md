# Cursor Rules

Always use:

- TypeScript
- Server Components when appropriate
- Supabase
- Tailwind
- Shadcn

Never add unnecessary complexity.

Avoid over-engineering.

Create reusable components.

Follow feature-first architecture.

Every page must be mobile responsive.

Every form must be validated.

Every API route must be typed.

All code should be production ready.

Prefer composition over duplication.

Use clean folder structures.

Create scalable code.
