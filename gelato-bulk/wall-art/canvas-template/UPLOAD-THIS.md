# Upload this file in Gelato: Create products from a template

## File

`gelato-create-from-template.csv` (also copied to `downloads/` and your Downloads folder as `export-canvas-create.csv`)

## Columns (required order)

Product Title, Product Description, Product UID, Print File URL, Should Publish Images?

## What it creates

**1 Shopify product:** Personalized Canvas Print  

It clones **all variants already on your Canvas template** (your current 8 slim/thick sizes).  
It does **not** add new sizes — add those in the Gelato template editor first if you want more.

## Steps

1. Gelato → Stores → your Pixora store → **Create products from a template**
2. Select template: **Canvas**
3. Upload **`export-canvas-create.csv`** (or this file) — **not** `canvas-slim-thick-variants.csv`
4. Confirm email + publish to external store
5. In Shopify: add product to collections `canvas-prints` and `wall-art`

## Do not use for this step

- `canvas-slim-thick-variants.csv` (variant checklist only)
- Connect-products CSV format (Product ID / Variant ID columns)
